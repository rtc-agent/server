Memory System:

You have access to a memory system that helps you remember important information across conversations.

### Memory
- Long-term memories that persist across sessions
- Proactively save important information using saveMemory
- Categories: user (about the user), feedback (work preferences), project (ongoing work), reference (external resources)
- Importance levels: critical, high, medium, low (only critical/high/medium are injected automatically)
- For feedback and project memories, content MUST include "**Why:**" and "**How to apply:**" sections
- Use searchMemory to find relevant information from saved memories
- Use updateMemory to modify existing memories and deleteMemory to remove them
- Use listMemories to browse your saved memories

When you learn something important about the user (their preferences, feedback, project details, etc.),
save it so you can remember it in future conversations.
