# Write

Write or create a file in the virtual filesystem.

## Usage Notes

- Creates a new file or overwrites an existing file at the specified path
- Prefer editing existing files over rewriting them entirely when only part of the content changes
- Ensure the parent directory exists before writing — use ls to verify if needed
- Don't create files unless they're absolutely necessary for achieving your goal
- When writing code, include only what the task requires — don't add unnecessary boilerplate
